## 1. 总体风格

扁平、极简、以线条构形。

- **无投影、无渐变、无色块填充**。层级只靠三样东西建立：1px 发丝线、字重、三级灰阶。
- **窗口与卡片同为纯白**，不靠底色分区。区域边界一律用 1px 线划出。
- **强调色全局只出现在三处**：输入焦点、主操作按钮、链接。其余一概灰阶。
- 按钮全部为线框（含主操作），不使用实心填充按钮。
- 动效克制：加载用静态骨架线，不用旋转动画；卡片展开收起不做弹跳。

**「无填充」的三个例外**，只有这三个，再加就要重新讨论：

1. **截图遮罩** `#F1F2F4`——它表达的是「屏幕被压暗」，不是层级。
2. **开关 / 单选 / 复选里的圆点与方勾**——它们是控件状态本身。
3. **电平表与进度线**——1px 竖线／横线的深浅两段，用的是线不是块。

### 应用名

界面上的应用名**永远只写 `Su-Su`**：

- 不带「词典」二字，也不带任何后缀。
- **不随显示语言变化**——界面切成中文、日文、英文，标题栏、托盘、关于页写的都是 `Su-Su`，不本地化、不音译、不加副标题。
- 复合标题写成 `Su-Su · <功能>`，中点是 `·`（U+00B7），前后各一个空格：`Su-Su · OCR`、`Su-Su · 视频转写`。
- 连字符用 ASCII `-`，不要用 `–`／`—`；两个 S 都大写。
- 标题栏 12.5 / 600，`letter-spacing: 0.02em`；关于页 18 / 600。

| 名称 | 值 | 用途 |

| 发丝线 | `#E4E6E9` | 卡片边框、分隔线、禁用态边框 |
| 纸白 | `#FFFFFF` | 窗口底色、卡片底色（同色） |
| 强调色 | `#2D64E0` | 输入焦点、主操作、链接 |
| 链接悬停 | `#1F4CB4` | `a:hover` |
| 禁用文字 | `#A7ACB3` | 禁用按钮文字 |
| 错误文字 | `#A03A2C` | 请求失败提示 |
| 骨架线 · 深 | `#E4E6E9` | 加载首行 |
| 骨架线 · 浅 | `#EDEFF1` | 加载次行 |
| 窗口外框 | `#D9DCE0` | 窗口 1px 外边框 |

对比度（在纸白上）：墨黑 17.8:1，次级灰 6.2:1，提示灰 4.3:1，强调色 `#2D64E0` 5.2:1。提示灰略低于 4.5:1，只用于 11px 以下的字数、耗时、标注这类辅助信息，**不要再调浅**；正文与控件文字一律用墨黑或次级灰。**新增颜色前先验对比度**。

强调色是可替换的。备选：墨黑 `#16181D`、墨绿 `#0F7A6B`、赭石 `#B4531F`。换色只需改这一个值，界面其余部分不受影响。

### 深色 token

|---|---|---|---|

| 提示灰 | `#757B84` | `#8E939C` | 5.4:1 |
| 强调线 | `#C9CDD3` | `#4B5058` | — |
| 发丝线 | `#E4E6E9` | `#2F333A` | — |
| 骨架线 · 浅 | `#EDEFF1` | `#272B31` | — |
| 纸白 → 纸黑 | `#FFFFFF` | `#1C1E23` | — |
| 窗口外框 | `#D9DCE0` | `#3A3F47` | — |
| 次按钮边框 | `#D0D3D8` | `#444951` | — |
| 强调色 | `#2D64E0` | `#6C9BFF` | 6.2:1 |
| 链接悬停 | `#1F4CB4` | `#8FB4FF` | 8.1:1 |
| 禁用文字 | `#A7ACB3` | `#5E636B` | 2.8:1（禁用态不计） |

深色下强调色**不能**沿用 `#2D64E0`（在纸黑上只有 2.9:1）。强调色备选的深色档：墨白 `#E6E8EB`、墨绿 `#3FB8A5`（6.8:1）、赭石 `#E08A5A`（6.3:1）。三级灰阶在深色下的对比度都高于浅色。

**主题切换的要求**（首版只实现浅色，但结构从第一天就按这个来）：

1. 设置「主题」三选一：浅色 / 深色 / 跟随系统。
2. 全部颜色挂在根元素的 CSS 自定义属性上，按 `:root[data-theme="light"|"dark"]` 两套取值；界面代码只引用 token，不写字面色值。切换只改这个属性，**不重建 WebView2**，保温态的窗口也即时跟随。
3. 跟随系统 = 宿主监听 `UISettings.ColorValuesChanged`，写入 `data-theme`；页面里的 `prefers-color-scheme` 只作首帧兜底，最终以宿主下发为准。标题栏非客户区用 `DWMWA_USE_IMMERSIVE_DARK_MODE` 同步。
4. 托盘图标按**任务栏**而不是应用主题选单色版（第 6 节），两者独立。
5. 三处填充例外规则不变，只换 token：截图遮罩用 `#0F1013`，电平表与进度线的深浅两段用墨白 / 发丝线。

## 3. 字体

```css
font-family: "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI",
             "PingFang SC", system-ui, sans-serif;
```

用 Windows 11 系统字，中英混排基线一致，小字号下 hinting 最清晰，与系统 UI 天然统一。

### 字阶

| 字号 / 字重 | 行高 | 用途 |
|---|---|---|
| 21 / 600 | — | 界面标题 |
| 15.5 / 400 | 1.62 | 原文输入 |
| 14.5 / 400 | 1.75 | 译文正文（行距更松） |
| 12.5 / 600 | — | 引擎名称 |
| 12 / 400 | — | 控件文字、下拉选择 |
| 11 / 400 | — | 字数、耗时、快捷键提示、标注 |
| 10.5 / 400 | — | 标签、卡片内极次要信息 |

### 字体授权（重要）

栈内字体**均为专有字体**，非开源，但作为系统自带字被应用调用属许可范围内，零成本。三条红线：

1. **不得把字体文件打进安装包**，只能依赖系统已装字体渲染。
2. **不得做成 webfont**（若日后有网页版或 Electron 内 `@font-face`）。
3. **对外宣传物料另选字**。微软雅黑字库著作权属方正，超出 Windows 系统范围的商业使用（官网、商店宣传图、海报、包装）存在维权风险。

若日后跨平台或需要可嵌入分发，换用：中文 **思源黑体**（SIL OFL 1.1）或 **MiSans** / **HarmonyOS Sans**；西文 **IBM Plex Sans** / **Source Sans 3**。

## 6. 图标

16px 画布，**1.5px 描边，圆头圆角，`fill="none"`，`stroke="currentColor"`**。全部自绘，不引入第三方图标库，不使用 emoji。

已有（基础）：展开、折叠、交换语言、朗读、扬声器、复制、收藏、清空、重试、置顶、设置、截图 OCR、麦克风。

已有（功能与设置）：输入翻译、划词、剪贴板、视频、检查更新、退出、快捷键、引擎网格、AI 星芒、提示语、生词本、地球、信息、拖拽把手、加、减、删除、勾、眼睛、文件夹、文件、导出、外链、关闭、警告、计时、播放、暂停、停止、搜索、接口。

新增图标必须沿用同一描边规格和视觉重量。仅图标的按钮必须带 `aria-label`。

### 应用图标 / 应用标记

同一个标记，既是桌面与任务栏上的应用图标，也是标题栏、托盘里的应用标记。

**形**：一个 S —— 两条横线被一段曲线接上，把一行字搬到另一行。180° 旋转对称。

```
64 网格（1 单位 = 4px @256）
M16 16h20a8 8 0 0 1 0 16H28a8 8 0 0 0 0 16h20

16px 版就是它除以 4，仍落在整数格上：
M4 4h5a2 2 0 0 1 0 4H7a2 2 0 0 0 0 4h5
```

| 项 | 值 |
|---|---|
| 笔画 | 画布 × **9.375%**（16px 时 1.5px——与界面图标 1.5/16 同一比例） |
| 圆弧半径 | 画布 × 12.5% |
| 内容框 | 画布 × 50%；含笔画外缘 × 59% |
| 底板圆角 | 画布 × 18.75% |
| 底板外框 | 恒 **1 物理像素**，`#C9CDD3`，不随尺寸缩放 |
| 端点 | 圆头圆角，与界面图标一致 |

**色**：纸白底板 + 墨黑笔画。变体两个：强调色版（笔画换强调色，底板不动）、反白版（墨黑底板 + 纸白笔画）。

**托盘版**去掉底板，只留笔画：浅色任务栏用墨黑，深色任务栏用纸白。

**导出**：`.ico` 打包 16 / 24 / 32 / 48 / 256；托盘单色版另出 16 / 20 / 24（对应 100% / 125% / 150% 缩放）。因为几何全部落在 16 的整数格上，**一条路径从 16px 用到 256px 不需要重画**。

**不要**：加投影 / 渐变 / 外发光；旋转或倾斜；改笔画粗细比例；在图标里加「词典」或任何文字；把底板换成强调色。

### 第四版设置交互补充

- **借用剪贴板**：保留默认关闭。说明改为「可能进入剪贴板历史、同步到云端或被其他应用读取；会尽力恢复原内容，检测到新复制时保留新内容」。无法安全快照时不模拟复制，沿用取词失败提示；恢复失败另用悬浮条「未能恢复剪贴板，当前内容已保留」。
- **凭据输入**：复用现有密码框，只在用户新增/替换时显示真实 `<input type="password">`；保存的旧值只显示文本「已保存」和「替换」「删除」动作，掩码不是回填后的真实 key。眼睛仅显示尚未保存的新输入。保存成功/取消/切页/关闭清空；导入导出密码相同，保温前不能留值。
- **凭据绑定**：输入/关联账户时显示将使用该账户的具体服务与完整目标地址；腾讯翻译/OCR/TTS 或 AI/ASR 共用账户必须由用户选择关联，不凭服务名称自动关联第三方插件。新增 origin 或变更用途在保存前显示变更并确认。界面用「此服务将向 <地址> 发送凭据」说明用户选择，不展示 secret parts 等内部协议。
- **插件网络确认**：地址必须显示协议、主机、端口；例如 `http://127.0.0.1:11434` 与 `http://127.0.0.1:8765` 不能缩成同一个 `127.0.0.1`。安装确认中的密钥说明改为「凭据由 Su-Su 保存，只用于你授权的服务地址；请信任接收凭据的服务」。运行方式用「受限插件进程」，不再显示过期 Worker 或宣称不存在任何可写文件。
- **MyMemory 展开区**：保留日额度与邮箱配置，另加「单次最多 500 UTF-8 字节，长文本自动分段」；日额度注明按 IP 共享，本机用量不等于账户/共享 IP 剩余额度。
- **语音识别设置**：拆为「语音／音频转写」与「视频转写」两组，各有服务、模型与已关联账户状态，默认 OpenAI / whisper-1。前者可选纯文本模型；后者只允许具备时间码能力的模型。Gemini 基线仅用于前者；不在设置中展示为已验证模型，验证状态来自实际检查。热键/托盘的不可用规则按 PLAN 1.2；相关行说明「需配置支持时间码的转写服务」。

控件沿用本节现有规格，新增行按正常内容滚动排布。上述规格已全部落在画板上（第 17 版）。

## 8. 卡片结构

原文卡片与译文卡片共用同一骨架：

```
┌ 1px 边框，8px 圆角 ─────────────────┐
│ 头部  38px                          │
│   左 26px 折叠键 · 名称 · 标签       │
│   右 耗时 · 成组图标键               │
├ 1px 分隔线（仅原文卡片有）───────────┤
│ 正文  左内边距 38（与名称对齐）       │
├ 1px 分隔线（仅原文卡片有）───────────┤
│ 脚部  40px                          │
└─────────────────────────────────────┘
```

- **原文卡片**用 `#C9CDD3` 边框，译文卡片用 `#E4E6E9`，以此拉开主次。
- 头部固定 38px，正文左内边距 38px 与引擎名对齐。
- 译文卡片无分隔线，头部与正文直接相接。

### 卡片状态

| 状态 | 表现 |
|---|---|
| 原文 · 空态 | placeholder「输入或粘贴要翻译的内容…」，翻译按钮禁用，字数 0 |
| 原文 · 聚焦 | 边框换成强调色（全局唯一使用强调色的常态） |

| 译文 · 翻译中 | 两根骨架线（1.5px，100% 深 / 62% 浅），右侧「翻译中」，无动画 |
| 译文 · 词条 | 音标行（英/美 + 朗读键）+ 词性缩写（30px 定宽斜体）+ 释义 |
| 译文 · 失败 | 一行 `#A03A2C` 错误文字 + 一个动作，卡片不变形不跳动。按插件错误协议的七类分别给：`timeout` / `network` / `rate_limited` 宿主自动重试一次后才显示，动作「重试」；`quota` 与 `auth` 不重试，动作「去设置」链接；`bad_response` 动作「查看日志」；`unsupported_language` 不进正文，卡片折叠并在右侧标注「不支持 <源> → <目标>」 |

## 9. 窗口

### 窗口位置（所有窗口共用）

**没有任何窗口贴着鼠标弹出。**

- **设置窗口**每次打开都居中于当前屏幕（鼠标所在显示器的工作区），不记忆位置。
- **其余全部窗口**（主窗口、悬浮窗、OCR 结果窗、视频转写窗）关闭时记下位置，下次在上次关闭的位置打开；**拿不到上次位置时居中**——从未开过，或记下的位置已不在任何显示器的工作区内，两种情况处理相同。
- 每类窗口各记各的坐标；划词与剪贴板是同一个悬浮窗壳，共用一份。
- 只记位置，不记大小。
- 两个例外，因为它们必须指向触发点：**发音浮条**贴选中文本、**错误悬浮条**贴鼠标。

规则的完整定义在 `PLAN.md` 1.4.1。

主窗口 520×700，1px `#D9DCE0` 外框，8px 圆角。

- **标题栏 40px**：左侧 16px 应用标记 + 12.5/600 应用名；右侧置顶、设置（各 36×32），再接 Windows 11 系统按钮（**46×32**，最小化 / 最大化 / 关闭）。
- **内容区**：内边距 14，卡片间距 10。
- **状态栏 32px**：左侧快捷键提示（11px 提示灰），右侧文字链接。

### 悬浮窗（划词 / 剪贴板 / 语音 / 音频）

宽 **380**，高度由内容撑开。没有系统按钮，**头部 34px 就是语言对那一行**：左侧「源语言 · 交换 · 目标语言」，右侧置顶、在主窗口打开、关闭（各 26×26）。

**只由快捷键唤出**：划词选中文本后不画浮标、不画按钮，选区旁什么都不出现。窗口在上次关闭的位置打开，不跟随鼠标，所以状态栏左侧写「Esc 收起 · 关闭时记住位置」，**不再有「鼠标移出自动收起」**——窗口既然不在鼠标附近，移出鼠标就不能再作为收起的信号，只能由 Esc 或关闭键收起。

- 原文不做成独立卡片，直接铺在头部下方，用一根发丝线与译文列表分开；原文脚部 34px 放字数与图标键。
- 译文列表内边距 10，卡片间距 10——比主窗口紧一档。
- 状态栏 32px：左「Esc 收起 · 关闭时记住位置」，右「固定」链接。

### 结果窗（OCR 420×620 / 视频转写 760×580）

用主窗口那套壳：40px 标题栏 + 系统按钮 + 32px 状态栏，只是宽高不同。

**视频任务设置**：选文件后在文件信息区显示「转写服务／模型」「翻译引擎」与「开始转写」按钮，确认前不上传。显示媒体时长、预计音频片数/转写用量及翻译引擎的限制；识别前用「翻译字符量待识别」，不能伪造总价。选择 MyMemory 时显示「单次 500 UTF-8 字节；日额度按 IP 共享，长内容可能中途用完」。这不是首次启动引导，也不新增独立向导窗口。

转写开始后保留现有双语列表。MyMemory 额度耗尽时只暂停翻译投递，已识别原文和时间码仍可复制/导出；状态行提供「更换翻译引擎」，更换后只处理未完成字幕。纯文本 ASR 不进入视频模型选项；字幕按 ID 对齐，分片状态用现有状态文字表达。

**OCR 的截图选区上没有工具条**：1px 强调色边框 + 四角 9px 短线 + 选区右上角 10.5px 尺寸标注，此外只有一行 10.5px 提示「按住左键拖动框选 · 松开即完成 · Esc 取消」。整个截图只有一个手势——按住左键、拖、松开，松开即完成，遮罩消失，结果窗随即在上次关闭的位置弹出并开始识别。原先工具条上的四个按钮：识别后是否自动翻译由设置项决定，「重选」变成结果窗里的「重新截图」，「取消」是 Esc。

### 全局提示条（悬浮条）

卡片之外的错误只有三种承载，画板 `Error.dc.html`：
