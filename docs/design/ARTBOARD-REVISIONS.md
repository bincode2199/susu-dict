# 第四版画板同步清单

> 上级：[ARTBOARDS](ARTBOARDS.md) · 文档目录：[docs/README](../README.md)

状态：**已同步**（2026-09-19，线上第 17 版）。`*.dc.html` 与 `canvas.json` 已从线上导出回本目录，浅色与深色一并更新。执行时的两处取舍见 [RECORD.md](../product/RECORD.md) D-58；下表保留作验收核对。

所有修改先做浅色，再按既有 token 映射生成深色，同步对应 `Dark*` 画板。无需新建配色或窗口壳。

| 画板 | 变更 |
|---|---|
| SetGeneral | 「允许借用剪贴板取词」说明替换为「可能进入剪贴板历史、同步到云端或被其他应用读取；会尽力恢复原内容，检测到新复制时保留新内容」。保持默认关闭 |
| Error | 增加「未能恢复剪贴板，当前内容已保留」悬浮条；不能再承诺排除历史/云同步 |
| SetEngines | MyMemory 展开区增加「单次最多 500 UTF-8 字节，长文本自动分段」；日额度与本机用量分开说明；腾讯账户选择明确标识关联的服务 |
| SetEngines / SetOcr / SetAI / SetNetwork | 已保存凭据只显示「已保存」及「替换」「删除」，不回填旧值；眼睛仅针对新输入；账户/地址绑定变更显示目标地址并在保存前确认 |
| SetGeneralB | 导入/导出密码按输入期清空规则处理；安装确认显示完整协议/主机/端口；「ES Module + Worker，只能发 HTTP」改为「受限插件进程」；密钥说明改为「凭据由 Su-Su 保存，只用于你授权的服务地址；请信任接收凭据的服务」；旧「安装后需要重启 Su-Su」改为「安装时会重启插件服务，正在处理的请求将中断」 |
| SetAI | Ollama 保存提示显示完整 `http://127.0.0.1:11434`，不能只显示 127.0.0.1；更换 origin 时重新确认 |
| SetSpeech | 原共享转写服务一行拆成「语音／音频转写」和「视频转写」，分别选服务/模型并显示关联账户；默认 OpenAI/whisper-1。普通录音允许 Gemini/gemini-2.5-flash，视频只列时间码模型；不复用翻译模型、不标记未实际验证的连接为成功 |
| Tray / SetHotkeys | 只有纯文本 ASR 时视频仍置灰，对应说明「需配置支持时间码的转写服务」；语音/音频不受影响 |
| Transcribe | 增加已选文件、尚未开始状态：原文件区域内放服务/模型、翻译引擎、开始按钮；显示时长、估算片数/转写用量与「翻译字符量待识别」。MyMemory 显示字节上限及共享日额度说明 |
| Transcribe | 增加翻译额度耗尽状态：保留原文/时间码和已完成译文，停止该引擎投递，提供「更换翻译引擎」，只继续未完成字幕；仍可导出原文，不重新调用 ASR |
| Main / Selection / Ocr / Voice | 长文本按服务限制切分后仍一服务一卡片；需要分片时状态文字为「已分段翻译」，不增加新卡片或改变原文 |

验收时核对：画板不包含旧的无历史污染、密钥绝不进入任何 WebView、无任何可写文件系统或 Worker 执行方式的承诺；凭据授权只写用户能理解的服务/地址，不能把内部 secret/IPC 协议塞入产品界面。
