## Scope and contracts

| Sub-task | Delivered |
|---|---|
| F03.1 | `susu.exe` (`src/Susu.Host`) chooses its startup mode first: main, `--plugin-host` and `--selection-host`. The child modes are refused with exit 64 until F04/F08, and no main-mode service starts for them. Single instance: a per-user mutex named from the data root; a second launch wakes **only** that instance and grants it foreground rights. Tray icon (`Shell_NotifyIcon` v4): the monochrome icon follows the taskbar theme, it is re-added after an Explorer restart, left click does nothing, double click opens Settings, right click opens the menu window, and Windows notifications report background failures. Global hotkeys use `RegisterHotKey` with `MOD_NOREPEAT`; refusals show in Settings ("注册失败，请换一个", registration failed, choose another) and as a notification. A missing WebView2 Runtime gets a native prompt that opens Microsoft's official page on consent; nothing is downloaded by Su-Su. All Win32 code is in `Susu.Windows/Shell`; WebView2 hosting is in the native `susu_native.dll` (`shell_webview.cpp`). |
| F03.2 | Vue SFC application in `ui/src` (see [UI](../../architecture/UI.md)): colour tokens (light implemented, dark reserved), zh-Hans/en resources, title bar, result/source card, toggle, stepper, setting row, one-way secret field, hotkey recorder, and 16 px line icons. The typed bridge uses `protocol/generated/ui.ts`, which now also generates `UI_COMMANDS`. Security layers: page CSP; native origin lock (trusted virtual host per window, `settings.susu.example` separate from `app.susu.example`); navigation, frame, new-window, download, permission and foreign-resource blocking; host objects, devtools, context menus, autofill, zoom and browser accelerators off. The host (`Susu.Ui/Shell.cs`) validates version, session, schema and the per-window command whitelist. State flows as snapshot plus sequenced patches; streaming is coalesced to at most 30 per second; the page resyncs on a gap. The artboard HTML is not loaded. |
| F03.3 | Windows are placed in 96-DPI DIPs converted per monitor (`PlacementPolicy`, Per-Monitor V2 manifest, `WM_DPICHANGED`). Main, result and float windows reopen at their remembered position if it is still reachable, else centered on the cursor's monitor; Settings always centers. Size is never remembered and the window is clamped into the work area; floats stay at most the work height minus 32 DIP. Maximize fills the work area and is not remembered. A native no-activate waiting shell (GDI) is available for F08. Keep-warm hides and suspends the WebView; 10 minutes after the last window hides, every controller closes, the environment is released and `BrowserProcessExited` is awaited. Minimize hides to the tray and keeps the task; close cancels the window's task and hides, or exits when "close exits" is set. Keyboard: Enter inserts a new line, Ctrl+Enter submits, nothing submits during IME composition, and Esc closes popups or recorders first, then the window. Opening a window moves focus into the page. |
| F03.4 | Minimal settings: General (UI language, translation languages, cards expanded by default, clipboard borrowing, close action, start with Windows, theme placeholder), Hotkeys, service pages (enable toggles and per-secret credential fields), Network (proxy mode, host, port, user, password through the same secret path, AI timeout). Saves carry `expectedRevision` and the file hash, so conflicts and invalid input come back with exact issue paths. Credential writes are one-way (`Secret.WriteNew`/`Delete` from Settings only) through the journaled settings + secrets commit. The dev preview (`-p:SusuDevPreview=true`) adds fixture services that show loading, streaming, success, error, quota and unsupported states. Release builds contain no fixtures, and input translation is listed as "尚未提供" (not available yet) until F06. |

Not included: floats (selection/clipboard/voice), OCR and transcription windows beyond their placement rules (F08, F11–F14). Shared-account binding and origin grants in the UI come in F05/F07. Dark theme is later. Export/import is F17.

Contract changes: `Susu.Contracts/UiViews.cs` (snapshot, window, tray, settings views and requests), the `Window.OpenSettings` command, and `UI_COMMANDS` generated into `protocol/generated/ui.ts`. New ports: `IConfigService` and `IWindowPlatform` (`Susu.Abstractions/UiPorts.cs`).
