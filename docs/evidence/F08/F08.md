## Scope and contracts

- **F08.1:**
  - **Assembly:** selection lives in a new assembly `Susu.Windows.Selection`, not in `Susu.Windows`. `Susu.Windows` references sockets, while the new assembly references only `Susu.Abstractions`, so a test that walks its references proves the helper can't reach accounts or the network (ARCHITECTURE § 3 row added).
  - **Native:** `susu_selection.dll` (UIA plus IA2; several selections are merged in document order).
  - **Helper:** `susu.exe --selection-host <hwnd> <uiaMs> [ia2]`: MTA thread, one JSON line per run, 2 s watchdog; the rectangle is in physical px with the monitor DPI.
  - **Interface:** `ISelectionReader { Snapshot(); ReadAsync(snapshot, ct); Prime(hwnd) }` in `Susu.Abstractions/SelectionPorts.cs`; production instance `new SelectionReader(Win32SelectionPlatform.ForCurrentProcess())`.
  - **Timing:** the 500 ms acquire deadline includes process start. A newer read supersedes the older one.
  - **Failure cache:** Unsupported, Timeout, HelperFailed and Elevated results are cached for 60 s per PID + start time + window class. After 3 helper failures in a row, no helper is launched for 30 s. A cold browser/Electron window returns `NotReady` once. The 200 ms snapshot deadline belongs to F08.2 (the clipboard snapshot).
- **F08.2:**
  - **Ports and flow:** ports in `Susu.Abstractions/ClipboardPorts.cs`. `ClipboardBorrower` (borrow state machine) and `CaptureCoordinator` (UIA/IA2, then the optional borrow) live in `Susu.Jobs`. The Win32 side is `Susu.Windows/Clipboard/` plus a `susu.exe --clipboard-host` helper.
  - **Capture:** the hotkey takes the foreground snapshot before any Su-Su window opens. `ShellCoordinator.Captured(CaptureOutcome {Status, Text, Source, FailureKey, Message, Notice, Rect, Dpi})` fires for the current capture only; `CaptureCoordinator.TranslateAsync` serves tray and clipboard entry points.
  - **When borrow runs:** it doesn't run on Empty, Password or Elevated.
  - **Format whitelist:** also covers the shell file-list companions (Preferred DropEffect, Shell IDList Array, FileName/FileNameW). OLE plumbing formats are dropped from the snapshot instead of refusing the borrow.
  - **Selection helper timeouts:** the helper now signals ready. A timeout is cached only after ready; a slow start still counts toward the restart breaker.
  - **Priming:** foreground-change priming is not wired, because it would turn on every browser's accessibility tree. A cold window gets one retry after NotReady instead.
- **F08.3:**
  - **Selection window:** a text or empty capture opens it with its own translation session. It is activated only after capture completes (UI03). Placement follows PLAN 1.4.1 / DESIGN 9: the last-closed position, else centered, never near the pointer. The coordinator confirmed the spec over the task brief; the outcome's Rect/Dpi are not used for the window.
  - **Failure bar:** failures show near the pointer, never take focus, and hide after 4 s. It is 460 DIP wide.
  - **Tray:** offers clipboard translation only, never selection.
  - **Features:** Selection and Clipboard are registered Available.
  - **SetHotkeys:** a sharing tag on selection and clipboard; conflicts and RegisterHotKey refusals appear as one error line naming the chord; the borrow toggle says the copy lands in Win+V history (C07; DESIGN says "may").
  - **Contracts:** new commands `Window.OpenInMain` and `Window.FitContent`; new views `CaptureView` and `ErrorBarView`; new platform method `FitHeight`.
