## Scope and contracts

- **F08.1:**
  - **Assembly:** selection lives in a new assembly `Susu.Windows.Selection`, not in `Susu.Windows`. `Susu.Windows` references sockets, while the new assembly references only `Susu.Abstractions`, so a test that walks its references proves the helper can't reach accounts or the network (ARCHITECTURE § 3 row added).
  - **Native:** `susu_selection.dll` (UIA plus IA2; several selections are merged in document order).
  - **Helper:** `susu.exe --selection-host <hwnd> <uiaMs> [ia2]`: MTA thread, one JSON line per run, 2 s watchdog; the rectangle is in physical px with the monitor DPI.
  - **Interface:** `ISelectionReader { Snapshot(); ReadAsync(snapshot, ct); Prime(hwnd) }` in `Susu.Abstractions/SelectionPorts.cs`; production instance `new SelectionReader(Win32SelectionPlatform.ForCurrentProcess())`.
  - **Timing:** the 500 ms acquire deadline includes process start. A newer read supersedes the older one.
  - **Failure cache:** Unsupported, Timeout, HelperFailed and Elevated results are cached for 60 s per PID + start time + window class. After 3 helper failures in a row, no helper is launched for 30 s. A cold browser/Electron window returns `NotReady` once. The 200 ms snapshot deadline belongs to F08.2 (the clipboard snapshot).
