## Scope and contracts

| Sub-task | Delivered |
|---|---|
| F01.1 | `Susu.Contracts`: `IpcEnvelope` with a strict decoder that rejects unknown types, unknown fields, missing required fields, future versions and oversize frames before any dispatch. Also `ProtocolNegotiation` (version, role, build), `ErrorKind` with the plugin names, plugin API v1 **candidate** DTOs with ASR segment validation, the UI envelope, card snapshot/patch and a per-window command whitelist (secrets only from Settings; no generic HTTP/file proxy). `tools/Susu.ContractsGen` generates `protocol/generated/ui.ts` and `susu-plugin.d.ts`, and `--check` reports drift. Compatibility samples are in `protocol/ipc/samples/`. |
| F01.2 | `Susu.Domain`: package, instance, account and service identity (`PackageId`), `CapabilityResolver` (availability per capability and credential), page-local reorder, `ConfigSnapshot` with a timeout ceiling, canonical language codes and a script fast path, `TextChunker` (UTF-8 byte, UTF-16 and scalar limits; paragraph → sentence → space boundaries; never splits a code point), `SubtitleMapper` (ID matching, part split/merge, batch validation). |
| F01.3 | `JobStateMachine` (terminal states are final; pause only for pausable pipelines), `EventStamp` generation/attempt/sequence, `RetryPolicy` (one automatic retry, shared deadline, `Retry-After` ≤60 s, reset before a retried stream, writes never retried), `RuntimeRegistry` (capability disable versus forced rebuild), `CardReducer`. `Susu.Jobs`: `InvocationScheduler` has a global limit of 8, per-instance and account+origin limiter keys, category limits (video ASR), a bounded queue that fails fast when busy, and fair background admission after five interactive ones. Queued cancellation is immediate. `TranslationSession` produces snapshot + patch projections with no window references. |
| F01.4 | `FeatureRegistry` only exposes features whose services are ready. `tests/Susu.Testing` has `ManualClock`, `FixedJitter`, `RecordingUsage` and `ScriptedProvider` (streams, gates, failures). No vendor or system capability is implemented. |

Not included: real providers (F05/F06), IPC transport and plugin host (F04), persistence (F02), UI (F03). The plugin API stays a *candidate* until the G1 contract probes pass.

Consumers: `protocol/generated/*.ts` is consumed by the F03 UI. Any contract change must regenerate these files (the drift test fails otherwise) and update `protocol/ipc/samples`.

## Minimal demonstration

There is no user-visible demo in F01. The executable demonstration is the test suite. For example, `TranslationSessionTests` submits text to three scripted services. Two expanded cards stream, one collapsed card waits. Then a late old-generation result arrives and is ignored, and a partial stream fails and is retried once with a reset.
