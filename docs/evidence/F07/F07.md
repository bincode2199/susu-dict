## Scope and contracts

- **F07.1:** `ReorderServiceRequest.merged` (the index is a position in the merged translation + AI list); `ServiceView.usageThisMonth` (local monthly characters, wired translation packages only); `TranslationBackend.MonthlyUsage` ← `UsageRepository.Count(id, "chars", "yyyy-MM")`. Types are regenerated in `protocol/generated/ui.ts`.
- **F07.2:**
  - **Config schema:** the manifest `config` schema (types, enums, uri, min/max, `x-susu` group/secret/showWhen/placeholder/help/optionsSource) is parsed. Unknown keywords are rejected, and `dependsOn` may name only the package's own fields and secrets. `ConfigSchema.Check` validates values on the host.
  - **`OptionsBroker`:** 10 s timeout with cancel, a 200-item page cap, a 5-minute cache and dependency revisions. A stale revision returns Stale and is never cached.
  - **Contracts:** `ServiceView.config` and `instanceRevision`; `Settings.SaveServiceConfig` (Settings window only; an address change revokes the old origin's grant); `Settings.LoadOptions` → `OptionsView`.
  - **Invalidation:** saving or deleting a key invalidates the option lists of every service on that account.
  - **Config values:** they reach plugins as strings.
  - **OpenAI:** `baseUrl` (uri, advanced) and `model` (options from GET `/v1/models`, depends on baseUrl and apiKey). A custom origin is passed per call and must be confirmed as a grant.
- **F07.3:**
  - **Prompt rendering:** `PromptTemplate` replaces `{{text}}`, `{{from}}`, `{{to}}` and `{{level}}` in one pass. Unknown names and anything inside the source text stay literal. A template that uses `{{text}}` twice is refused on save.
  - **Prompt scope:** only AI services in the chosen scope receive `TranslateRequest.prompt`. A provider keeps the prompt snapshot it was built with. `AppSettings.Prompt` is the `prompt:` section in settings.yaml.
  - **Model parameters:** reach a plugin only when its schema declares them (OpenAI `temperature` 0–2).
  - **Commands:** `Settings.SavePrompt`, `Settings.PreviewPrompt`, `Settings.TestNetwork` (one result per service origin, run through a broker built from the edited proxy settings).
  - **F05 broker change (reviewed by the coordinator):** the connection to a user-configured proxy may go to loopback or the LAN; a direct connection is still checked; the broker refuses a CONNECT from a caller; loopback services bypass the proxy. Residual risk: through a proxy, the proxy resolves the target, so the broker's LAN-address check can't apply to the target host. Origins are still limited to declared and granted ones.
  - **Not built:** the per-service proxy scope ("适用范围"); the proxy applies to all remote services.
