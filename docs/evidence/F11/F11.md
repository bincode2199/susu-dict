## Scope and contracts

- **F11.1:**
  - **Port:** `IScreenCapture.CaptureRegionAsync()` → `ScreenCaptureResult`: captured, cancelled (escape/tooSmall/busy) or failed (`capture.failed`, `capture.diskFull`, `capture.writeFailed`; a failed kept copy is reported in `CopyErrorCode`).
  - **Image:** a captured result carries a `ScreenshotImage`: a PNG file lease (`File.LeaseId` for broker grants), the region in physical pixels, and the DPI of the monitor holding most of it. `ShellCoordinator.ScreenCaptured` subscribers own and dispose the image.
  - **Capture code:** `GdiScreenGrabber` (F00 decision) and the native `RegionOverlay`. Su-Su windows are hidden before capture and restored after.
  - **Entry points:** the OCR hotkey and tray item reach the port only when the feature resolves Available; it stays InDevelopment until F11.3.
  - **Retention (ARCHITECTURE 8.4):** the temporary image follows the lease rules, and a cancel or failed write leaves no file (OCR01). Kept copies go to Pictures/Su-Su only when "keep" is on (off by default, OCR03), and are listed in an index under LocalAppData. Startup cleanup walks only that index and removes copies older than 7 days (configurable). It keeps files a task still leases, never touches replaced or foreign files, and deletes nothing if the index is damaged (DATA08). The spec sets no size cap for screenshots.
