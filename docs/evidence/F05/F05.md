The master required SSE streaming through the bridge with `StreamWindow` credit in F05 (F06 streaming and S09 chunk limits depend on it). WS only if a v1 adapter needs it.

Abandoned streams are cleaned up. 4 new real-sandbox tests; 313/313. WS: not required by any v1 adapter (checked against the PLAN adapter list), so not built. The oversized single-chunk S09 test over loopback TCP was timing-dependent; the master required a deterministic test one layer down (in-memory stream, single read and 1-byte reads).

Four in-memory stream tests exercise `NetworkBroker.DecodeTextFromStream` against the broker's cap check, including disposal of the upstream. Writing them exposed two real bugs, both fixed: bursts spread over several reads were never coalesced, so the cap check was nearly dead; and the first coalescing fix could start a second concurrent read on the same stream. 317/317, run twice.
- 2026-09-24: F05.4 probes, part 1 (`c1792fb`): translate batch, options and vocab upsert run through the real sandbox against local test servers. The reusable adapter `CapabilityClient` was added. 321/321.
