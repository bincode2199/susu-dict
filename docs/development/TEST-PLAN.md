# Su-Su · 开发与发布验收计划

> 上级：[开发](README.md) · 根目录：[README](../../README.md)

范围：PLAN 第四版、ARCHITECTURE A1、DEV-PLAN F00–F19。保留 R01–R06 的原始 47 项并补充任务、性能、UIA、设置、UI、存储、媒体与更新验收。本文件定义开发出口条件，不是通过报告；各用例的执行结果记在模块交付记录（`docs/evidence/Fxx/Fxx.md`）中，汇总见 [PROGRESS](../evidence/PROGRESS.md)。每模块按 DEV-PLAN 选取用例；同一用例的原型、纯逻辑、契约回放和真实端到端结果分别记录。

运行记录须注明应用/插件 commit、.NET/引擎/WebView2 版本、Windows build、CPU 架构、服务/model/API 版本和日期。凭据使用测试账户；日志、录制响应与失败附件均脱敏。真实调用结果和录制响应测试结果分别记录，不能互相替代。

| B08 | 错误/普通 JSON/二进制/Base64 超限、缺少 Content-Length、压缩膨胀 | 按实际处理字节和协议上限中止；不造成无界 IPC/内存/临时文件增长 |

| S06 | audioUrl、WS 握手、插件/应用更新 URL、代理测试越界 | 均进入各自宿主授权策略，不存在 `$http` 之外的自由网络出口 |
| S07 | 设置页输入→保存/取消/切页/关窗/保温→重开 | 只短暂持有新值；已存值不回传、不进浏览器持久存储；眼睛不能读取旧 key |
| S08 | 结果窗口调用凭据动作、页面导航、更换 origin、译文含脚本/第三方恶意 SVG | origin/窗口/动作校验拒绝；译文当文本、图标安全处理，不能取得宿主能力 |
| S09 | 伪造 pluginId、账户、任务令牌；帧/流块/并发/日志超限 | 主进程按其登记的授权校验，过期调用拒绝，资源有界；不把原生失陷后的跨插件令牌窃取算作已防御 |
| S10 | 测试服务器回显原始/标准 URL/Base64 凭据，日志带敏感 detail | 已知形式拦截，日志无认证/正文；另记录任意变形回显不在保证范围，不能用 S10 通过宣称密钥绝不回流 |

| J05 | 429 的秒数/日期/非法/超长 Retry-After；网络/鉴权/额度/结构错误 | 分类、一次重试与 60 s 等待上限符合架构；供应商/HTTP 不再叠加重试 |
| J06 | 多能力包禁用一个能力；同时两调用之一死循环或无限微任务 | 另一启用能力不被正常禁用操作卸载；强制重建时所有受影响调用明确失败；其他包可用 |
