# Windows VMs

> Parent: [README](../../README.md)

The two general-purpose Windows 11 virtual machines (`win11-dev` for development, `win11-clean` for clean testing) that Su-Su is built and tested in. For day-to-day work only the operations manual is needed; the other three documents record how the VMs came to be.

| Document | Purpose | Read when |

| [WINDOWS-VM-DEPLOYMENT](WINDOWS-VM-DEPLOYMENT.md) · 部署记录 | What was deployed and verified on 2026-09-21 | You need the evidence behind the current state |
| [WINDOWS-VM-PLAN](WINDOWS-VM-PLAN.md) · 安装部署计划 (V5) | Decisions, layout, install phases and acceptance criteria | You question a design decision or plan new VMs |
| [WINDOWS-VM-REVIEW](WINDOWS-VM-REVIEW.md) | Multi-round review of the plan and its implementation | You trace why the plan reads the way it does |
